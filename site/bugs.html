Go

  • net/http hides why a new HTTP/2 connection failed

Node.js

  • A watch mode test restarts when other tests create files beside it

Git

  • Two git notes add at once silently drop one of the notes
  • Two credential-cache daemons started at once lose a stored credential

Nix

  • A new store's database is busy when several processes open it at once
  • The gc-closure test can fail with SIGPIPE

Flox

  • Activations that start and exit together corrupt each other's state
  • Two concurrent flox activate -s restart each other's services
  • A finished activation's on-deactivate hook runs alongside the next on-activate
  • The on-deactivate hook runs after on-activate failed
  • flox install and flox edit fail in containers

nixd

  • Formatting hangs on large files, can kill nixd with SIGPIPE, and leaks fds

Jujutsu

  • Three test_converge tests fail when operations end in the same millisecond

process-compose

  • Shutdown hangs when a process restarts as the project ends
  • A SIGTERM during startup leaves processes running after process-compose exits

Pueue

  • A task added right after pueue reset is deleted by the reset

watchexec

  • One run's --timeout kills the restarted run
  • A signal forwarded during a restart kills the new run
  • watchexec fails to start when HOME does not exist

concurrently

  • A signal during --teardown leaves the teardown command running
  • Input to a command that closed its stdin crashes concurrently

Supervisor

  • A daemonizing supervisord returns before its pidfile exists
  • A program that fails at once is restarted forever when its child holds its output
